- Filtrar y seleccionar datos con precisión
- Crear nuevas variables calculadas
- Realizar análisis agregados por grupos
- Combinar múltiples fuentes de datos

- Encadenar operaciones de manera fluida
- Resolver problemas reales de BI

## 📦 Paquetes necesarios
```r
install.packages("tidyverse")  # Incluye dplyr, tidyr, y más
```

## 💡 Conceptos clave
- **dplyr**: Manipulación de datos (SQL para R)
- **tidyr**: Reestructuración de datos
- **pipe operator** (%>%): Encadenar operaciones
- **tidy data**: Datos organizados y limpios
